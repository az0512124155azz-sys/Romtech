# RomTech — חנות ופאנל ניהול

אתר חנות בעברית, RTL, עם קטלוג, הזמנות, ביקורות, ניהול מוצרים ותוכן וחיבור Supabase ללקוח שרוכש את האתר.

## התחלה

```text
npm ci
npm run build
npm run dev
```

האתר זמין ב־`http://127.0.0.1:4173`. אזור הניהול נמצא ב־`/admin/`.

ללא הגדרת שרת זו הדגמה מקומית: ניהול הנתונים נשמר בדפדפן ומוצגת הודעה ברורה. לקבלת הזמנות וביקורות משותפות יש להשלים את החיבור.

## חיבור Supabase

[מדריך ההתקנה למוכר וללקוח](docs/SUPABASE-SETUP.md) מסביר את ההגדרה החד־פעמית של OAuth ו־Redis ואת משתני השרת. אחרי ההגדרה הלקוח מתחבר לחשבון שלו, בוחר/יוצר פרויקט ומפעיל הגדרה אוטומטית מתוך הניהול.

המערכת יוצרת טבלאות עם RLS והרשאות מפורשות, אחסון תמונות, בדיקת תקינות, החלפת פרויקט והעברה ראשונית מהדפדפן. פרטי החיבור משותפים לכל המכשירים. הסודות נשמרים מוצפנים בשרת; הדפדפן מקבל מפתח publishable בלבד. ניהול ענן מאומת בשרת.

## בדיקות

```text
npm test
npx playwright install chromium
npm run test:browser
```

כולל PostgreSQL ב־PGlite, הרשאות ופרטיות, backend OAuth מול ספק מדומה ודפדפן מול שרת בדיקה. אפליקציית OAuth וזרימה מול Supabase חי עדיין דורשות את ההגדרה במדריך.

## פריסה

`vercel.json` מגדיר את `api/romtech.js` ואת האתר הציבורי ב־`dist`. תהליך הבנייה מעתיק רק קבצים ציבוריים. אין לפרסם את תיקיות השרת, הבדיקות או קובצי הסודות באמצעות שרת סטטי.
