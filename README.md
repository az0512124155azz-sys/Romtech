# RomTech — שטריימלים מהודרים

אתר חנות ופאנל ניהול בעברית, RTL, שנבנו לפי מסמך האפיון של RomTech.

## מה קיים בגרסה הזו
- קטלוג מוצרים עם חיפוש, סינון וכרטיסי מוצר
- דף מוצר עם גלריה, מפרט, מלאי, מחיר ו-WhatsApp
- פאנל ניהול: הוספה/עריכה/מחיקה, שכפול, Bulk Edit, CSV import/export
- עד 10 תמונות למוצר (נשמרות מקומית ב-localStorage בגרסת ה-static)
- שדות SEO, SKU, ברקוד, מלאי, עלות, מבצע, גובה, שיניים, פרווה, בטנה, קופסה ורקמה
- סרגל נגישות: גודל טקסט, ניגודיות, גופן קריא, עצירת אנימציות והדגשת קישורים
- Cookie Consent גרנולרי
- דפי: נגישות, פרטיות, תקנון, ביטולים, משלוחים, עוגיות, FAQ וצור קשר
- כפתור WhatsApp למספר +359 87 985 8846
- sitemap.xml + robots.txt

## הרצה
אין build. פותחים את `index.html` דרך שרת סטטי, לדוגמה VS Code Live Server.

## חשוב לפני Production
גרסה זו היא static-first ומשתמשת ב-localStorage לצורך הדגמה/ניהול מקומי. לפני אתר מסחרי אמיתי צריך לחבר Backend/DB, אחסון תמונות, סליקה, אימות מנהלים, חשבוניות, משלוחים ואבטחה בצד השרת.

הטקסטים המשפטיים הוטמעו לפי האפיון שסופק, אך אינם תחליף לבדיקה משפטית פרטנית של העסק, פרטי העוסק והפעילות בפועל.
